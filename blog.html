Oct 31, 2026 · explainer

What is PSSA? A state space language model in pure Rust

PSSA is a small language model built on a state space architecture instead of attention. Where a transformer re-reads its whole context window for every token, a state space model carries a fixed-size recurrent state forward, so the cost of the next token does not grow with the length of what came before. It belongs to the same family of architectures as S4 and Mamba: selective state space models.

Three things set PSSA apart from a standard selective scan. A 512-slot episodic memory bank is read and written during the run, with keys retrieved by hyperbolic distance inside the Poincaré ball. Part of the weights are plastic: fast updates reinforce what works while a refractory gate rate-limits overwrites, and a closed-form ridge regression folds the fast updates back into the base weights. And there is no ML framework underneath: the whole thing is hand-written Rust with a scalar CPU reference that every gradient is checked against.

On a parameter-matched run over the same 12.7M-token corpus, PSSA finished at 3.98 training cross-entropy against 4.43 for the transformer, and the gap holds on unseen text (3.997 vs 4.429 on a 198,939-token held-out slice). On the same CPU it trains 4.1x faster and generates 200 tokens in 226 ms against 2,735 ms.

Everything is open: the Rust source on GitHub, the full architecture write-up, and the model card on Hugging Face.

Oct 30, 2026 · collab

NSC64 trained a 109M PSSA in PyTorch

NSC64 ported the architecture to PyTorch and trained the result from scratch: 4B tokens in two phases, 50/50 TinyStories and FineWeb-Edu, then an 85/15 web/story fine-tune. The port keeps the same scan and memory-bank design as the Rust reference; the two departures it needed at this scale are backprop truncated at 256 tokens and the scan running as a fused Triton kernel with a hand-written backward that matches a plain PyTorch loop to about 1e-7.

Held-out scores, 1M unseen tokens per corpus, batch 8, sequence length 512: TinyStories 1.312 cross-entropy (3.71 perplexity, 64.8% next-token accuracy) and FineWeb-Edu web 2.866 (17.6 perplexity, 44.2% next-token accuracy). Web loss was still falling at 4B, so more tokens would help.

The weights are public: bf16 model.safetensors, a 16k byte-level BPE tokenizer and a self-contained loader that runs a plain scan on CPU and the Triton kernel on CUDA. See the model card for samples and the full write-up.

Oct 26, 2026 · training

The 105M run is underway

Training checkpoints from the 105M run land on pssa-checkpoints-run2 as the run goes. They are raw .pssa resume files rather than a packaged model, so they are useful for resuming and auditing, not for direct inference.

The goal stays the same as the roadmap says: a same-scale transformer baseline, so the small-scale gap gets asked at a scale that matters.

# Donating and sponsorship

PSSA is a research project run by one person. Every result on this repository
was trained on free hosted notebook GPUs, a few hours at a time, which caps how
large any single run can get. Sponsorship funds compute and nothing else.

In return you get named in the write-up of any result your hardware made
possible. Get in touch before sending anything so the details can be agreed.

highest-leverage thing anyone can offer this project.

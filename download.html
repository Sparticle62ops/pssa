Get PSSA.

Everything ships from GitHub and Hugging Face. No installers, no accounts, no telemetry: binaries, source, and model weights are public.

Download for your platform

Detects your OS and architecture and grabs the matching build from the latest release. Looking for something else? All releases.

Prebuilt binaries

github.com/Sparticle62ops/pssa/releases

Tagged releases carry builds for Linux x64 and ARM64 (glibc and musl), macOS Apple Silicon and Intel, and Windows x64. Grab one, chmod if needed, run.

Build from source

github.com/Sparticle62ops/pssa

Plain Rust, no framework underneath. Clone the repo and cargo run --release gets you the CLI and the TUI. Works on CPU, CUDA and WebGPU.

Model card & checkpoints

huggingface.co/sparticle62/pssa

The trained PSSA weights and the full model card live on Hugging Face, with training checkpoints published as the runs go.

Quick start

release tarball
tar xzf pssa-x86_64-unknown-linux-gnu.tar.gz
./pssa --help
from source
git clone https://github.com/Sparticle62ops/pssa
cd pssa
cargo run --release

The README covers training, the TUI, and converting checkpoints. Questions land in the Discord.

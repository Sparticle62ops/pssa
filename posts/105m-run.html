The 105M run is underway

Training checkpoints from the 105M run land on pssa-checkpoints-105m as the run goes. They are raw .pssa resume files rather than a packaged model, so they are useful for resuming and auditing, not for direct inference.

The goal stays the same as the roadmap says: a same-scale transformer baseline, so the small-scale gap gets asked at a scale that matters.

4. Current extraction and bugs found

episodic bank, adapter, MLP, and continuous activation/adjoint buffers. PSSALayerV2 owns the shared
embedding/head, token/target/logit/loss tape, tokenizer metadata and one optimizer clock. The block
receives raw continuous rows and returns raw-input adjoints from arbitrary supplied output adjoints.
The audit found no concrete algebra, random-draw-order, optimizer-order, or V7 serialization-order
drift. That is a source audit, not a replacement for executable parity tests.
Fixed during this continuation:
- An allocation regression test still referenced the former model.memory field rather than
model.block.memory, preventing full test compilation.
- The earlier continuous-inference test pre-normalized input, although the new block now owns
normalization. It now passes raw embedding rows and retains its exact output/state assertions.
- Checkpoint allocation accounting missed four new chunk-by-width buffers plus one width-sized
inference buffer. Checked accounting was increased by (4 * chunk_len * d_latent + d_latent) *
4 bytes. This fixes the loader's allocation-budget estimate without changing V7 bytes.

norm/SSM/query/memory/adapter/MLP parameters with nonempty detached memory, VJP
scaling/additivity, split-chunk carry and detachment, endpoint-only embedding scattering,
vocabulary-independent block storage, and actual counted zero-allocation paths. Tests must pass
before these are treated as proven properties.

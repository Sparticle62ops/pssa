Technical deep dive

How PSSA works, in full.

Every mechanism below is taken from the source and the published checkpoints: a selective diagonal state-space recurrence, a 512-slot episodic memory with hyperbolic keys, plasticity through closed-form consolidation, and a gradient harness that checks every kernel against a scalar reference on every commit.

Numbers on this page come from the measured checkpoint chain and the benchmark runs. Where a value is schematic (for example the softmax mix shown on the main page) it is labeled as such.

02 · Episodic memory

Keys on a hyperbolic ball, values in flat space.

Each of the 512 slots holds a key on the Poincaré ball and a value in ordinary Euclidean space. Distance on the ball grows sharply near the boundary, so broadly reused context sits near the origin and one-off episodes sit near the edge; a single distance function separates them without any learned metric.

dH(u, v) = arccosh(1 + 2 ‖u − v‖2(1 − ‖u‖2)(1 − ‖v‖2) ) (1)
dH — hyperbolic distance on the Poincaré ball.
‖·‖ — Euclidean norm of the slot key.
arccosh — inverse hyperbolic cosine; real-valued on [1, ∞).

The read is an exact scan. A query is formed from the current token embedding and the recurrent state, every occupied key is scored, and a softmax over negative distance turns the scores into a mix:

qh = proj(Wqx xt + Wqh ht) (2)
ws = softmax(− dH(qh, ks)τmem)  ,  m = Σs ws vs (3)
qh — state-conditioned query, projected to the ball.
ks, vs — key and value of slot s.
τmem — temperature; smaller values sharpen the mix.
m — the retrieved value, blended into the block output.

The write path is round-robin by design: a pointer advances through the 512 slots one per token, and two gates decide whether the target slot may actually be overwritten. A novelty gate blocks writes that carry nothing new, and a refractory counter protects a recently written slot from immediate erasure. Capacity is therefore fixed and forgetting is explicit, not a side effect of a growing cache.

An optional flag, --memory-top-k K, still scans all 512 keys but mixes only the K best values. It exists for speed experiments; exact full-scan read is the default and the benchmarked path.

03 · Selective recurrence

One state, updated in place.

The core is a selective diagonal state-space recurrence in the Mamba family: the transition is diagonal, the step size and the input map are functions of the current token, and nothing outside the state is consulted.

δt = softplus(Wδ xt)  ,  At = exp(δt A)  ,  Bt = δt B (4)
ht = At ⊙ ht−1 + Bt ⊙ xt (5)
xt — the embedded token, 256 channels.
ht — the state, 256 × 16, carried across tokens.
δt — per-channel step size, selecting how far the token reaches back.
⊙ — elementwise product over the 16 states per channel.

Sixteen log-spaced time constants give the state horizons from 1.5 to 200 tokens before training moves anything, so short-range spelling and long-range topic structure coexist from initialization. Because A is diagonal and the recurrence is written scalar-first, every batched and parallel kernel has a plain reference implementation to be checked against.

04 · Plasticity

Two speeds of change, one closed-form fold.

A per-token gate decides how much of the memory read is admitted, and a rank-16 adapter carries the fast path:

g = sigmoid(wgate · xt)  ,  A(xt) = W2 silu(W1 xt) (6)

At consolidation boundaries, the statistics the adapter accumulated are folded back into the base transition matrix by a ridge solve:

Abase ← Abase + (HTH + λI)−1 HT ΔH (7)
H — the accumulated input statistics since the last boundary.
ΔH — what the fast path changed for those inputs.
λ — the ridge penalty, keeping the solve well-conditioned.
(HTH + λI)−1HT — the closed-form ridge solution; no optimizer state, no learning-rate schedule.

The result is a model whose reading changes what its next read retrieves: memory writes are gated by novelty and refractory counters, and the fast adapter shifts behavior between consolidation points. The scope is honest: this is measured on a 12.7M-token run, not claimed as a general training recipe.

05 · Verification

Every shortcut has a reference.

A scalar reference path computes each gradient by hand, one element at a time. Every batched and parallel kernel is finite-differenced against it on every commit, and the harness fails the build on disagreement.

max | ∂batched − ∂scalar | ≈ 2.98 × 10−8 (8)

The measured maximum disagreement across the kernel set is 2.98 × 10−8, within the 3 × 10−8 gate. Finite-difference spot checks run alongside. This is why the results below can be quoted as model behavior rather than as artifacts of a fast-but-wrong kernel.

08 · Scope and limits

What this is, and is not.

PSSA is a 1.54M-parameter research prototype, trained once on a small corpus. It is not a general-purpose model, and the benchmarks compare it to one baseline at matched size, not to frontier systems. The claims that are load-bearing are the ones that are checkable: exact full-scan memory reads, a diagonal recurrence written scalar-first, closed-form consolidation, and a gradient harness with a measured 2.98 × 10−8 maximum disagreement. One seed, one run: the checkpoint chain is published so every number above can be re-derived.
